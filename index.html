常见问题

守灯在后台还会继续吗？

会。守灯结束时间是真实的时刻，切到后台、锁屏或重启 App 后都会按真实时间结算。如果结束时刻已过，下次打开 App 时会自动点亮绑定的航标并结算奖励。

守灯结束后没有点亮航标？

检查这次守灯是否绑定了航标。未绑定时只记专注时间，不会点亮航标。如果绑定后仍未点亮，请备份存档并把备份文件和大致时间发给我们。

潮汐可以改吗？

潮汐由海面决定，每天自动生成；你可以在今天页查看今天的容量与灯油倍率，但不需要（也不能）手动切换。超出容量的航标，灯油会减半。

光链怎么算？

同一天内，连续点亮三枚同分类航标即形成光链；每多一枚同类航标，灯油加成 +10%，最多 +30%。断链后重新累计。

存档会丢吗？

存档保存在本机。卸载 App 会删除存档，所以重要进度请用「设置 → 存档备份」导出一份。换设备时用同一份备份导入即可。

怎么删除账号和全部数据？

设置 → 守灯人账号 → 删除账号与全部数据。确认后立即清除账号绑定、进度、守灯记录、航线、挑战、剧情和引导标记，无法恢复。

天气为什么不准？

天气来自 Open-Meteo，按粗粒度位置取最近的城市级数据。拒绝定位权限时，天气不会显示，其余功能不受影响。

支持哪些系统？

iOS 17 及以上，iPhone，竖屏使用。

FAQ

Does a watch keep running in the background?

Yes. A watch stores a real end time, so it settles by wall-clock time across backgrounding, locking, and relaunching. If the end time has passed, the bound beacon is lit and rewards settle the next time the app opens.

The watch ended but no beacon was lit.

Check whether the watch was bound to a beacon. An unbound watch only records focus time. If it was bound and still did not light, export a save backup and send it to us with the approximate time.

Can I change the tide?

The tide is generated for the day and shown on Today with its capacity and oil multiplier. It is not a manual switch. Going over capacity halves lantern oil.

How does the light chain work?

Light three beacons of the same category in a row on the same day to start a chain. Each extra same-category beacon adds +10% oil, up to +30%. Breaking the sequence resets it.

Will I lose my save?

The save lives on this device. Deleting the app deletes it, so export a backup from Settings → Save backup before switching devices, and import it on the new one.

How do I delete my account and data?

Settings → Keeper account → Delete account and all data. Confirming clears the account binding, progress, watch history, routes, challenges, story, and onboarding flags immediately. It cannot be undone.

Why is the weather inaccurate?

Weather comes from Open-Meteo using a coarse, city-level location. If you deny location access, weather is hidden and everything else keeps working.
